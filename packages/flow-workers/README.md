# option-flow-workers

Separate optional R26 orchestration package, version0.1.0a1. Executes batch,
chronological cuts and complete retained-ledger checkpoint restore through the
reviewed option-flow contracts/calculations/I/O packages. Source implementation
is not yet artifact/runtime/release qualified.

A coordinator resource grant and externally anchored installed-cohort verification
are prerequisites for execution. Logical task reservation is not an RSS bound.
The closed runtime contains exactly the four flow packages and DuckDB1.5.6;
R25 execution uses its original separate environment. Full R26 remains gated on
actual equity producer integration. See `docs/r26/WORKER_IMPLEMENTATION.md` in the
repository for source evidence, limitations and required qualification.
